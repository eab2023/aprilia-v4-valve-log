# aprilia-v4-valve-log
Valve clearance and adjustment applet for Aprilia V4's

## How To Use:

1 - Download from here
2- Save to desktop
3 - Double-click
4 - Should open and render in browser of choice

## Note:
If you move this from your desktop to a different directory (i.e., Downloads), the storage persistence will change. Just keep that in mind. 


### Layout follows Amauri's RSV4 valve adjustment log sheet (Aprilia Moto Service). Spec values from the Aprilia service manual.
